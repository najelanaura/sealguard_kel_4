# Security Policy

Proyek pembelajaran, bukan sistem produksi. Detail: [docs/SECURITY.md](docs/SECURITY.md).

- Broker publik tidak punya autentikasi/ACL: jangan kirim data pribadi atau rahasia.
- Jangan commit `.env` (sudah ada di `.gitignore`).
- Laporkan celah lewat GitHub Issues tanpa detail sensitif.
