# sealguard_kel_4
Drop Test Box adalah sistem pendeteksi risiko kerusakan paket menggunakan accelerometer dan gyroscope pada dua HP. Sistem mengukur impact, jumlah benturan, dan rotasi, lalu mengklasifikasikan risiko (AMAN, PERLU DICEK, RUSAK) menggunakan threshold atau Decision Tree/Random Forest. Pengujian dilakukan dengan variasi ketinggian dan bantalan.
